## Что строим

Индикатор подключения и обработка ошибок. Визуальный статус (connected/disconnected/reconnecting), обработка WS-ошибок, автоматическое переподключение при разрыве соединения, отображение серверных ошибок (`type: 'error'`).

## Критерии выполненной задачи

- [ ] Индикатор подключения (визуальный статус в углу)
- [ ] Обработка событий WS: `open`, `close`, `error`
- [ ] Статусы: connected, disconnected, reconnecting
- [ ] Автоматическое переподключение при разрыве (exponential backoff или фиксированный интервал)
- [ ] Обработка сообщения `{ type: 'error', error: string }`
- [ ] Отображение текста ошибки пользователю
- [ ] Тесты на WebSocket client согласно «Решения по тестированию» родительского PRD
