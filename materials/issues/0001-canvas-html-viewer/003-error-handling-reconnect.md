## Родительский PRD

[materials/prd/0001-canvas-html-viewer.md](../../prd/0001-canvas-html-viewer.md)

## Что строим

Индикатор подключения и обработка ошибок. Визуальный статус (connected/disconnected/reconnecting), обработка WS-ошибок, автоматическое переподключение при разрыве соединения, отображение серверных ошибок (`type: 'error'`).

## Критерии выполненной задачи

- [x] Индикатор подключения (визуальный статус в углу)
- [x] Обработка событий WS: `open`, `close`, `error`
- [x] Статусы: connected, disconnected, reconnecting
- [x] Автоматическое переподключение при разрыве (exponential backoff или фиксированный интервал)
- [x] Обработка сообщения `{ type: 'error', error: string }`
- [x] Отображение текста ошибки пользователю
- [x] Тесты на WebSocket client согласно «Решения по тестированию» родительского PRD
