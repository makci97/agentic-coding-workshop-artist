## Что строим

Выпадающее меню справа сверху для управления видимостью слоёв. Извлечение уникальных `artist_name` из полученных штрихов, генерация чекбоксов для каждого артиста, перерисовка canvas только с видимыми слоями.

## Критерии выполненной задачи

- [ ] Выпадающее меню (dropdown) справа сверху canvas
- [ ] Извлечение уникальных `artist_name` из `snapshot`/`delta`
- [ ] Генерация чекбокса для каждого артиста
- [ ] Хранение состояния видимости (visible artists set)
- [ ] Перерисовка canvas при изменении видимости слоя
- [ ] Обновление списка при получении новых `artist_name` в `delta`
- [ ] Тесты на Layer Manager согласно «Решения по тестированию» родительского PRD
