## Что строим

Выпадающее меню справа сверху для управления видимостью слоёв. Извлечение уникальных `artist_name` из полученных штрихов, генерация чекбоксов для каждого артиста, перерисовка canvas только с видимыми слоями.

## Критерии выполненной задачи

- [x] Выпадающее меню (dropdown) справа сверху canvas
- [x] Извлечение уникальных `artist_name` из `snapshot`/`delta`
- [x] Генерация чекбокса для каждого артиста
- [x] Хранение состояния видимости (visible artists set)
- [x] Перерисовка canvas при изменении видимости слоя
- [x] Обновление списка при получении новых `artist_name` в `delta`
- [x] Тесты на Layer Manager согласно «Решения по тестированию» родительского PRD
