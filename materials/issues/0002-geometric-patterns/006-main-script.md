## Что строим

Главный скрипт запуска через `python -m patterns_generator <config.json>`. Связывает загрузку конфига, генерацию и отправку на сервер.

## Критерии выполненной задачи

- [x] `patterns_generator/__main__.py` — entry point для запуска
- [x] CLI аргумент: путь к JSON-конфигу
- [x] Чтение `.env` для SERVER_WS_URL и ARTIST_NAME
- [x] Пайплайн: загрузка конфига → генерация штрихов → регистрация → отправка
- [x] Вывод в консоль: статус отправки, количество штрихов
- [x] Обработка ошибок: нет конфига, ошибка сервера, нет соединения
- [x] Визуальная проверка: запуск и проверка результата на canvas

- `005-websocket-client.md` — нужен клиент для отправки
