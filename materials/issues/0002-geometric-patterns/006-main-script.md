## Что строим

Главный скрипт запуска через `python -m patterns_generator <config.json>`. Связывает загрузку конфига, генерацию и отправку на сервер.

## Критерии выполненной задачи

- [ ] `patterns_generator/__main__.py` — entry point для запуска
- [ ] CLI аргумент: путь к JSON-конфигу
- [ ] Чтение `.env` для SERVER_WS_URL и ARTIST_NAME
- [ ] Пайплайн: загрузка конфига → генерация штрихов → регистрация → отправка
- [ ] Вывод в консоль: статус отправки, количество штрихов
- [ ] Обработка ошибок: нет конфига, ошибка сервера, нет соединения
- [ ] Визуальная проверка: запуск и проверка результата на canvas

## Блокируется

- `004-pattern-generators.md` — нужен генератор
- `005-websocket-client.md` — нужен клиент для отправки
