## Что строим

Добавить базовые палитры цветов в `palette/` для использования в геометрических паттернах. Каждая палитра — это именованный список hex-цветов.

## Критерии выполненной задачи

- [ ] Создана палитра `geometric` — контрастные цвета для геометрии (3-5 цветов)
- [ ] Создана палитра `rainbow` — цвета радуги (6-7 цветов)
- [ ] Создана палитра `monochrome` — оттенки одного цвета (4-5 оттенков)
- [ ] Палитры экспортируются через `palette/__init__.py`
- [ ] Формат: `dict[str, list[str]]` где ключ — название, значение — список hex-цветов
