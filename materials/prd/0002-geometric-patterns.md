# Geometric Patterns

## Постановка проблемы

Художникам нужно программно генерировать геометрические паттерны и отправлять их на общий сервер с canvas. Текущая архитектура (`palette/`, `brushes/`, `painting/`) предусматривает генеративное рисование через Python-кисти, но не имеет готовых реализаций паттернов и способа их отправки на сервер.

## Решение

Создать Python-пакет для генерации геометрических паттернов с конфигурацией через JSON-файлы. Скрипт читает конфиг, генерирует штрихи и отправляет их через WebSocket на сервер.

## User Stories

1. Как художник, я хочу сохранить конфиг паттерна в JSON-файл, чтобы переиспользовать его и делиться с другими
2. Как художник, я хочу запустить локальный скрипт с конфигом, чтобы сгенерировать и отправить паттерн на сервер
3. Как художник, я хочу выбрать палитру цветов для паттерна, чтобы контролировать визуальный стиль
4. Как художник, я хочу задать параметры паттерна (центр, радиус, количество линий), чтобы влиять на композицию
5. Как художник, я хочу видеть результат на общем canvas сразу после запуска скрипта, чтобы получить обратную связь
6. Как разработчик, я хочу хранить конфиги в `patterns/*.json`, чтобы иметь единую структуру для всех паттернов
7. Как художник, я хочу выбрать тип паттерна (спираль, мандала, сетка), чтобы быстро получить нужный стиль
8. Как разработчик, я хочу валидировать конфиги перед отправкой, чтобы избежать ошибок на сервере

## Решения по реализации

### Модули

**Создать:**
1. `patterns/` — директория с JSON-конфигами паттернов
2. `patterns_generator/` — Python-пакет с генераторами и клиентом отправки

**Изменить:**
- `palette/` — добавить базовые палитры для геометрических паттернов

### Архитектура

```
patterns/
  ├── spiral.json
  ├── mandala.json
  └── grid.json

patterns_generator/
  ├── __init__.py
  ├── config.py      # загрузка и валидация JSON-конфигов
  ├── generators.py  # генераторы паттернов (spiral, mandala, grid)
  └── client.py      # WebSocket клиент для отправки штрихов
```

### Формат JSON-конфига

```json
{
  "name": "spiral_mandala",
  "pattern_type": "spiral",
  "center": [400, 300],
  "max_radius": 250,
  "num_spokes": 36,
  "colors": ["#FF5733", "#33FF57", "#3357FF"],
  "stroke_width": 2,
  "rotation_angle": 0,
  "params": {
    "spirals": 3,
    "density": 1.5
  }
}
```

### Интерфейсы модулей

**config.py:**
- `load_pattern(path: str) -> PatternConfig` — загрузка и валидация конфига
- `validate_config(config: dict) -> PatternConfig` — валидация полей, значения по умолчанию

**generators.py:**
- `generate_spiral(config: PatternConfig) -> list[Stroke]` — генерация спиралей
- `generate_mandala(config: PatternConfig) -> list[Stroke]` — генерация мандал
- `generate_grid(config: PatternConfig) -> list[Stroke]` — генерация сеток

**client.py:**
- `CanvasClient(ws_url: str, artist_name: str)` — класс для подключения к серверу
- `send_strokes(strokes: list[Stroke])` — отправка штрихов через WebSocket
- `register_artist()` — регистрация артиста на сервере

### Типы данных

```python
@dataclass
class Stroke:
    x1: float
    y1: float
    x2: float
    y2: float
    color: str
    w: float

@dataclass
class PatternConfig:
    name: str
    pattern_type: str
    center: tuple[int, int]
    max_radius: int
    colors: list[str]
    stroke_width: float = 2.0
    rotation_angle: float = 0.0
    params: dict = None
```

### API контракты

- **POST `/canvas/register`** — `{ artist_name: str }` → 200 / 409 / 422
- **WS `/canvas/ws`** — отправка `{ artist_name, segments: Stroke[] }`
- Сервер отвечает: `open`, `snapshot`, `delta`, `clear`, `error`

### Конфигурация подключения

- URL берётся из `.env`: `SERVER_WS_URL`, `ARTIST_NAME`
- Fallback на значения по умолчанию из `.env.example`

## Решения по тестированию

### Стратегия тестирования

- **Модульные тесты** — генераторы паттернов (проверка количества штрихов, диапазонов координат)
- **Интеграционные тесты** — отправка на test-канвас сервера (`/canvas/ws-test`)
- **Визуальная проверка** — запуск скрипта и проверка результата на canvas

### Модули для тестирования

- `generators.py` — каждый генератор возвращает непустой список штрихов с корректными координатами
- `config.py` — валидация некорректных конфигов
- `client.py` — регистрация артиста, отправка штрихов

### Примеры для ориентира

- `tests/server/test_canvas.py` — интеграционные тесты с сервером
- `tests/server/conftest.py` — фикстуры для подключения

## За рамками

- Интерактивное рисование мышкой в браузере
- Анимация процесса рисования
- Предпросмотр паттерна перед отправкой (PNG/SVG)
- CLI с параметрами командной строки
- Сохранение паттернов в бинарные форматы
- Сложные художественные стили (импрессионизм, абстракционизм)
- Поддержка пользовательских генераторов через плагины

## Дополнительные заметки

- Генераторы должны быть детерминированными (одинаковый конфиг → одинаковый результат)
- Координаты штрихов должны находиться в пределах холста (0..width, 0..height)
- Цвета могут задаваться как hex-строки (`#RRGGBB`) или названия (`red`, `blue`)
- Для сложных паттернов можно использовать несколько проходов генерации
