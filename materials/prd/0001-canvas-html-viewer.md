# Canvas HTML Viewer

## Постановка проблемы

Художникам и зрителям нужен standalone HTML-вьюер для отображения композиции штрихов на сервере в реальном времени. Сервер уже предоставляет WebSocket-канал (`/canvas/ws` и `/canvas/ws-test`), но не имеет готового клиентского вьюера, который можно открыть локально в браузере.

## Решение

Создать автономный HTML-файл `canvas/canvas.html`, который:
- Подключается к серверу по WebSocket и получает штрихи в реальном времени
- Рендерит композицию с помощью Canvas 2D API
- Предоставляет выпадающее меню справа сверху для управления видимостью слоёв по `artist_name`
- Поддерживает конфигурируемое подключение через query-параметр `?ws=<url>`

## User Stories

1. Как зритель, я хочу открыть `canvas.html` в браузере и видеть все штрихи на холсте в реальном времени, чтобы наблюдать за процессом рисования
2. Как зритель, я хочу видеть список всех артистов, которые рисовали на холсте, чтобы понимать, кто участвовал в создании композиции
3. Как зритель, я хочу включать и выключать видимость отдельных слоёв по имени артиста, чтобы изолировать вклад конкретного художника
4. Как зритель, я хочу видеть индикатор подключения к серверу, чтобы понимать, активно ли соединение
5. Как зритель, я хочу видеть обработку ошибок подключения, чтобы знать о проблемах с сервером
6. Как разработчик, я хочу задать URL WebSocket через query-параметр `?ws=...`, чтобы переключаться между main и test канвасами
7. Как разработчик, я хочу получить автономный файл без сборки, чтобы открыть его напрямую в браузере
8. Как зритель, я хочу, чтобы при потере соединения вьюер пытался переподключиться, чтобы восстановить отображение
9. Как зритель, я хочу видеть сообщение об ошибке от сервера (например, `unknown artist_name`), чтобы понимать причину проблемы

## Решения по реализации

### Модули

**Создать:** `canvas/canvas.html` — единый автономный файл

### Архитектура файла

- **HTML** — структура с `<canvas>` элементом и UI для меню слоёв
- **CSS** — стили для позиционирования меню (справа сверху), индикатора подключения, выпадающего списка
- **Vanilla JS** — без внешних зависимостей

### Компоненты

1. **WebSocket Client**
   - Подключение к URL из `window.location.search` (параметр `ws`) или default URL
   - Обработка сообщений: `open`, `snapshot`, `delta`, `clear`, `error`
   - Автоматическая переподключение при разрыве

2. **Canvas Renderer**
   - Инициализация `<canvas>` с размерами из `/canvas/config`
   - Отрисовка штрихов через Canvas 2D API (`moveTo`, `lineTo`, `stroke`)
   - Перерисовка при получении `delta` или `clear`

3. **Layer Manager**
   - Хранение состояния видимости для каждого `artist_name`
   - Выпадающее меню справа сверху со списком артистов и чекбоксами
   - Перерисовка canvas при изменении видимости слоя

4. **Connection Indicator**
   - Визуальный индикатор статуса (connected/disconnected/reconnecting)
   - Отображение ошибок сервера

### API контракты

- **GET `/canvas/config`** → `{ width: number, height: number }`
- **WS сообщения от сервера:**
  - `{ type: 'open', canvas: { width, height } }`
  - `{ type: 'snapshot', strokes: Stroke[] }`
  - `{ type: 'delta', strokes: Stroke[] }`
  - `{ type: 'clear' }`
  - `{ type: 'error', error: string }`
- **Stroke:** `{ x1, y1, x2, y2, color, w, artist_name }`

### Конфигурация

- URL WebSocket задаётся через query-параметр: `canvas.html?ws=ws://195.133.25.57/canvas/ws`
- По умолчанию: `ws://195.133.25.57/canvas/ws` (main канвас)
- Для test канваса: `canvas.html?ws=ws://195.133.25.57/canvas/ws-test`

## Решения по тестированию

### Стратегия тестирования

- **Ручное тестирование** — открытие файла в браузере, подключение к серверу
- **Визуальная проверка** — корректность рендеринга штрихов, переключение слоёв
- **Smoke-тесты** — аналогично `tests/server/test_canvas.py`, но с проверкой через DOM

### Модули для тестирования

- WebSocket client (переподключение, обработка ошибок)
- Layer Manager (переключение видимости)
- Canvas Renderer (корректная отрисовка)

### Примеры для ориентира

- `tests/server/test_canvas.py` — WS-протокол, структура сообщений
- `tests/server/conftest.py` — фикстуры для подключения к серверу

## За рамками

- Рисование из браузера (только просмотр, без отправки штрихов)
- Экспорт изображения в PNG/JPG
- Масштабирование и панорамирование холста
- Фильтрация по временным меткам
- Цветовая индикация артистов (если сервер не передаёт цвет)
- Массовые операции со слоями (показать все/скрыть все)

## Дополнительные заметки

- Файл должен быть полностью автономным (no build, no npm dependencies)
- Все стили и скрипты — внутри одного HTML-файла
- Меню слоёв должно быть доступным (клик по чекбоксу, hover-эффекты)
- Индикатор подключения должен быть заметным, но не навязчивым
